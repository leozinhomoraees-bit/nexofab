# Vídeo do topo

Coloque aqui o vídeo principal da produção com um destes nomes:

- `hero-oficina.mp4` (H.264, recomendado para compatibilidade)
- `hero-oficina.webm` (opcional, recomendado para reduzir o tamanho)

Especificação sugerida: 1920 × 1080 px, 12 a 20 segundos, sem áudio, em loop, com até 8 MB. O enquadramento deve manter máquinas e movimento no lado direito, deixando o lado esquerdo livre para o texto.

Se nenhum vídeo estiver presente, o site utiliza a arte abstrata do NexoFab. Usuários que ativaram “reduzir movimento” também recebem a versão estática.
